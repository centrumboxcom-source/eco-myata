# ЕКО М’ЯТА

Український магазин натуральних продуктів на Next.js App Router, TypeScript, Tailwind CSS, Zustand і Supabase.

**Почніть із [START-HERE.md](START-HERE.md): база, адміністратор, домен, Merchant Center, GA4/GTM і контроль запуску.**

## Запуск

Потрібен Node.js 22 або новіший.

```sh
npm ci
npm run dev
```

Вітрина: http://localhost:3000. Адміністративна панель: http://localhost:3000/admin.

Без параметрів Supabase показується демонстраційний каталог. Кошик і обране зберігаються в браузері. Демонстраційна адмін-панель змінює дані лише до перезавантаження сторінки; ці зміни не видаються за збереження у базі. Оформлення, підписка та авторизація повідомляють, що потрібне підключення. Реальні замовлення в цьому режимі не створюються.

## Що реалізовано

- Широкий мобільний пошук під логотипом усередині липкої шапки.
- Налаштування домену, продавця, політик, Google IDs у БД; перевірка готовності й відкриття продажів.
- /merchant.xml з GTIN/MPN, актуальною ціною, акцією, фото й залишками.
- GA4 або GTM після згоди, ecommerce-події, підтверджений online purchase.
- Галереї товарів, обкладинки статей, архів, статистика з БД та контроль повернення коштів.

- Адаптивна вітрина, меню для телефона, каталог, фільтри, сортування, картки та сторінки товарів.
- Живий пошук у шапці з фотографіями, цінами, клавіатурною навігацією та нечітким збігом: «арахова» знаходить «Арахісова». Enter для появи результатів не потрібен.
- Кошик, обране, зміна кількості, швидкий перехід до оформлення, українські контакти й адреси.
- Supabase Auth, відновлення пароля, історія власних замовлень; окремі права адміністратора.
- Товари й завантаження фото, категорії з батьківською категорією, промокоди, замовлення, статуси, ТТН та CSV, блог, модерація відгуків, контакти, SEO і способи оплати/доставки.
- Розрахунок цін і знижок у PostgreSQL; транзакційні залишки, блокування товарів, захист від дублювання запиту.
- Нова пошта: пошук міста, відділення та поштомата з серверним API ключем. Без ключа доступне ручне введення. Укрпошта й кур’єр — введення адреси, без створення накладних у API перевізника.
- Monopay та LiqPay: створення рахунку/платіжної форми, підписані callback-и; Apple Pay/Google Pay на стороні платіжного провайдера. Оплата при отриманні та IBAN.
- Динамічні sitemap/robots, метадані товарів і статей, Product JSON-LD, OpenGraph-зображення, next/image та lazy loading.
- Підписка зберігає email у БД. Розсилка листів потребує окремого сервісу та не відправляється автоматично.
- Instagram показує фото підключеного акаунта за серверним токеном; без токена відображається редакційна галерея з посиланнями на товари, а не вигадана соціальна стрічка.

Дивіться [SETUP.md](SETUP.md) — повна інструкція Supabase, створення адміністратора, платежів і доставки.

## Перевірки

```sh
npm run typecheck
npm test
npm run check:launch
npm run build
npm audit
```

Тест БД запускає міграцію в ізольованому PostgreSQL-сумісному середовищі PGlite. Він перевіряє серверні ціни, знижку, залишки, ідемпотентність, відкат невдалих замовлень, RLS, заборону зміни ролі покупцем та одноразове повернення залишків під час скасування. Тест не підключається до реальної Supabase-бази.

## Публікація

Стандартний Next.js сервер: `npm run build`, потім `npm start`. Для Cloudflare/Sites використовується OpenNext. `npm run build:cloudflare` будує Worker; `node scripts/stage-site.mjs` готує `dist/server/index.js` і `dist/client`. Мають бути увімкнені `nodejs_compat` та ASSETS. У Cloudflare next/image використовує IMAGES, якщо binding надано, і повертає вихідне зображення без нього. На звичайному Next.js сервері оптимізація зображень працює вбудовано.

Документація: [Next.js metadata](https://nextjs.org/docs/app/api-reference/functions/generate-metadata), [Supabase SSR](https://supabase.com/docs/guides/auth/server-side), [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security), [Monobank acquiring](https://api.monobank.ua/docs/acquiring.html), [LiqPay Checkout](https://www.liqpay.ua/doc/api/internet_acquiring/checkout?tab=1), [OpenNext](https://opennext.js.org/cloudflare).

Фото й промпти фірмових зображень: [ASSETS.md](ASSETS.md). Товари, ціни, склад, залишки та харчова цінність у seed — демонстраційні дані, які власник замінює на фактичний асортимент до продажів.

Перед `node scripts/stage-site.mjs` виконайте `npx wrangler deploy --dry-run --outdir .sites-runtime/worker`.

`node scripts/test-http.mjs` перевіряє локальний сайт на порту 3000 без підключеної Supabase. Не запускайте цей тест проти магазину, що приймає замовлення.
